# Darkroom Engineering

- **URL:** https://darkroom.engineering/
- **Category:** experimental-interaction
- **Slug:** `darkroom-engineering`

## Short description
Studio/lab behind Lenis and other MIT primitives. The public face is a bench of tools, not a case-study theatre.

## Why it is visually interesting
Open-source motion primitives are presented as a catalog of instruments. The brand is the engineering bench.

## Signature decision
Lab catalog: each library is a named instrument with a one-line job, not a campaign.

## Decisions that differ from a typical AI landing page
- Tools listed as products of a lab
- MIT as a visible attribute
- No fake case studies around an npm package
- Voice is engineer-direct
- Site points at repos and docs domains
- Avoids agency reel even though the tools power agency reels
- Reduced-motion stance lives in the tools themselves

## Reuse as a principle
If you make primitives, catalog them as instruments with jobs. Link the license.

## Do not copy directly
Do not copy Darkroom naming of tools you did not write.

## Brand-bound elements
Darkroom name, Lenis and sibling tool names.
