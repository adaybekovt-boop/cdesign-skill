## Hero composition
Principle: definition + invitation to scroll. Product UI can wait forever if the brief is stealth.

## Section structure
Principle: use the customer's workflow steps as the outline.

## Navigation
Principle: almost none. Footer is a room.

## CTA placement
Principle: contact after the posture is clear.

## Storytelling
Principle: name domains and steps; withhold internals.

## Cards
Principle: steps in a list beat feature cards.

## Grids
Principle: itinerary, not bento.

## Image treatment
Principle: one object (wheel) instead of a collage of stock.

## Transitions
Principle: 3D object as the cut between chapters.

## Footer
Principle: interactive close (form + motion) as the last scene.

## Responsive transformation
Principle: retime the story. Drop physics. Keep paper/ink and the itinerary.
