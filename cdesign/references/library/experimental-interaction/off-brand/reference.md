# OFF+BRAND.

- **URL:** https://www.off---brand.com/
- **Category:** experimental-interaction
- **Slug:** `off-brand`

## Short description
Studio behind Aether 1 and other awarded builds. Site language is abrupt, catalog-like, with experimental project entries rather than a soft agency story.

## Why it is visually interesting
The studio name is a typographic event (OFF+BRAND. / off---brand.com). Projects are filed like SKUs.

## Signature decision
Studio-as-catalog: naming, punctuation and project codes do the branding that a manifesto paragraph usually does.

## Decisions that differ from a typical AI landing page
- Domain punctuation is part of the identity
- Projects read as catalog entries
- Interaction is per-project, not a global shader wallpaper
- Type is sharp and abbreviated
- No 'about us' novel on home
- E-commerce honors work (Aether 1) sits beside experimental work without a vibe mashup
- Avoids both luxury serif and Inter-startup

## Reuse as a principle
Let naming, punctuation and catalog codes carry identity. Keep each project entry self-contained so one loud project cannot paint the whole studio.

## Do not copy directly
Do not copy OFF+BRAND naming tricks as a preset. Do not copy Aether 1.

## Brand-bound elements
OFF+BRAND wordmark, project roster, Aether 1 IP.
