# Exat Typeface — Hot Type

- **URL:** https://exat.hottype.co/
- **Category:** experimental-interaction
- **Slug:** `exat-typeface`

## Short description
Kinetic / structural microsite for Exat, a typeface by Hot Type drawn from Croatian modernism and the EXAT 51 group. Built by Studio Size with RISE2. Awwwards SOTD Apr 2025.

## Why it is visually interesting
The typeface is not shown as a specimen PDF. It is the entire interface: tester, historical names, width/weight matrix, and mouse-driven letter behavior share one modernist field.

## Signature decision
A typeface site where historical names (Picelj, Knifer, Richter…) and a live tester occupy the same composition as the marketing claim. Kinetic letter action is the product demo.

## Decisions that differ from a typical AI landing page
- Hero sentence and live tester share one field instead of 'Buy the font' above a pangram
- Vertical keyword 'modernism' runs as a side rail, not a tag pill
- Croatian modernist name list is treated as texture and content at once
- Width × weight matrix is a compositional object, not an account dashboard
- Mouse interaction drives letter behavior (Awwwards lists multiple mouse-interaction elements)
- History of EXAT 51 is the narrative spine, not a Features grid
- Two-color field (#1C1D1E / #EEEFEB) refuses chromatic specimen clichés

## Reuse as a principle
When the product IS a typeface, a tool, or a system, let the system occupy the hero as a working instrument. Side-rail keywords and name-lists can replace feature cards.

## Do not copy directly
Do not copy Exat letter shapes, Hot Type naming, EXAT 51 name list, or Studio Size motion timings. Do not reuse the exact two-hex pair as a 'modernist preset'.

## Brand-bound elements
Exat glyphs, Hot Type brand, EXAT 51 / Ivan Picelj history, Croatian modernist name list.
