## Entrance
Short load animation, then the tester and claim are already in place. Letters may settle from a constructed state.

## Scroll-linked behavior
Scroll reveals matrices and stylistic sets. History passages stay still; specimen objects can continue a slow kinetic idle.

## Section transitions
Hard cuts between paper-field sections. No cinematic wipes.

## Micro-interactions
Slider updates must feel instant (16ms frame). Stylistic-set toggles swap glyphs without layout jump.

## Hover
Glyph hover inspects a single character (alternate, encapsulated form). No scale-1.05 cards.

## Cursor behavior
Mouse is an input to letter construction, not a branded blob.

## Pinned sections
Tester can pin while you read the sentence above it. Do not pin every section.

## Parallax
Avoid. The field is flat on purpose.

## Shader / WebGL
Optional for letter construction; not required. If used, drive it from pointer, not from a looping noise field.

## Timing character
UI sliders = micro (instant). Kinetic letter demos = scene (800–1400ms) but only when demonstrating a feature.

## Reduced-motion
Freeze kinetic letters into static specimens. Keep the tester functional.
