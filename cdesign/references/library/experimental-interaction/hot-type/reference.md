# Hot Type

- **URL:** https://hottype.co/
- **Category:** experimental-interaction
- **Slug:** `hot-type`

## Short description
Type foundry. Catalog of faces where each typeface can earn a kinetic microsite (Exat) while the house site stays a foundry index.

## Why it is visually interesting
A foundry pattern: house index is calm; individual faces get experimental stages. Prevents every page from being a circus.

## Signature decision
Foundry index vs face stage: experimental energy is scoped to a single typeface URL.

## Decisions that differ from a typical AI landing page
- House ≠ face
- Each face can have a different stage
- Buying / testing is the foundry job; kinetic play is the face job
- Avoids turning the shop into WebGL
- Type is the product and the UI
- Opposite of a single animated landing for the whole catalog
- Pairs with Exat as a child pattern

## Reuse as a principle
Scope spectacle to the SKU URL. Keep the catalog usable.

## Do not copy directly
Do not copy Hot Type catalog or Exat.

## Brand-bound elements
Hot Type name and faces.
