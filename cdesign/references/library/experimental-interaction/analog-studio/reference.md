# Analog

- **URL:** https://analog.website/
- **Category:** experimental-interaction
- **Slug:** `analog-studio`

## Short description
Studio/site language built around analog constraints — film, paper, physical process — used as interaction metaphors (grain as evidence, cuts as edits, no fake glass).

## Why it is visually interesting
Experimental does not have to mean digital-native shaders. Analog metaphors produce a different motion and material set.

## Signature decision
Analog-process metaphor: cuts, grain, paper edges, edit-style transitions instead of lerp luxury.

## Decisions that differ from a typical AI landing page
- Grain as evidence of process, not a CSS overlay fad
- Cuts instead of eases
- Paper edges and misregistration as layout tools
- Photography treated like film stills
- Color from print processes
- Opposite of liquid glass
- Gives the engine an anti-shader experimental pole

## Reuse as a principle
Borrow film/print process as transition language. Use grain only when the brief is analog. Prefer cuts.

## Do not copy directly
Do not copy a specific Analog studio's work if it collides with brand rights. Treat this as a process pole.

## Brand-bound elements
Any studio wordmark using Analog as name.
