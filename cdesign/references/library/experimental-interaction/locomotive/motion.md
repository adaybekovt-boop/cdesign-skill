## Entrance
Type present. First scene waits for scroll or a short in-view.

## Scroll-linked behavior
Smooth interpolation + optional speed-based offset on images.

## Section transitions
In-view add/remove. Continuous animations use a second observer.

## Micro-interactions
Link underlines, not magnetic buttons by default.

## Hover
Low.

## Cursor behavior
Default.

## Pinned sections
Use sparingly; v5 no longer needs section containers.

## Parallax
Selected images only. Amplitude small. Off on touch.

## Shader / WebGL
Not required for the pattern.

## Timing character
Integrator smoothness. In-view 400–700ms.

## Reduced-motion
Native scroll, no lerp, no parallax. Instant in-view state.
