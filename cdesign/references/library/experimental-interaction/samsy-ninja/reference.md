# Samsy

- **URL:** https://samsy.ninja/
- **Category:** experimental-interaction
- **Slug:** `samsy-ninja`

## Short description
Creative developer portfolio historically built as an explorable WebGL room / ninja-coded playground. Navigation is spatial, not administrative.

## Why it is visually interesting
The portfolio is a place you move through. Menu items are objects or portals, not a CSS list.

## Signature decision
Spatial portfolio: sections exist as locations in a small world rather than anchors in a long page.

## Decisions that differ from a typical AI landing page
- Menu as portals / objects
- Home is a room, not a resume
- Technical flex is in the world's rules
- Mobile must get a different map, not a squeezed room
- Credits and contact are objects you find
- Avoids the scroll-hijack essay
- Personality is spatial humor

## Reuse as a principle
If the subject is play, put rooms and portals on home. Always design a non-spatial directory as the fallback.

## Do not copy directly
Do not copy Samsy's world, ninja motif, or camera rig.

## Brand-bound elements
Samsy identity and world assets.
