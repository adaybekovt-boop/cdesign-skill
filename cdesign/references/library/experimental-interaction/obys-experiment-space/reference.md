# Obys® Experiment Space

- **URL:** https://experiment.obys.agency/
- **Category:** experimental-interaction
- **Slug:** `obys-experiment-space`

## Short description
Interactive archive of unpublished Obys works, unused concepts and process fragments. Not a case-study portfolio — a continuously transforming spatial index.

## Why it is visually interesting
It treats unfinished work as the primary content and makes navigation itself the exhibit. Theme modes (White / Pride) rewrite the identity without changing the archive structure.

## Signature decision
Archive-as-space: projects live in a numbered stream that can flip between structured grid and horizontal visual flow. Desktop-only gate is an art-direction choice, not a bug.

## Decisions that differ from a typical AI landing page
- Content is unpublished / unused work, not shipped case studies
- Navigation is a spatial mode switch (structured forms ↔ horizontal streams) instead of a hamburger + grid of thumbnails
- White / Pride theme modes change palette and tone while keeping the same archive logic
- Live local time (CEST) sits in the chrome as a studio-presence signal
- Explicit desktop-only message: the experiment refuses to collapse into a mobile list
- About copy frames experimentation as a permanent studio condition, not a side page
- Numbered project index (01 Makhno Studio / 2021) reads like a finding aid, not a marketing deck

## Reuse as a principle
Treat an archive, process dump, or R&D log as a navigable space with two viewing modes rather than a filtered card grid. Let theme modes rewrite color and voice without inventing a second IA.

## Do not copy directly
Do not copy Obys wordmark, Pride-mode identity, project titles, or the exact White/Pride toggle labeling. Do not copy the desktop-only lock unless the brief truly cannot collapse.

## Brand-bound elements
Obys® naming, Pride mode as studio identity, specific unpublished project titles, CEST clock as studio timezone.
