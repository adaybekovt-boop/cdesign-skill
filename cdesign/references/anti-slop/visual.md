# Visual and material critique

Load when color, glass, grain, glow, gradients, illustration, 3D, or image treatment materially shapes the page.

Provenance: recurrence and trend claims are heuristic/internal pattern research.

## DEFAULT REJECT

### V-01 — Framework-default accent

An indigo/violet primary or familiar purple-pink/blue-cyan gradient is used because it is available, not because the brand, asset, reference, or data calls for it. A documented brand hue or product visualization can justify it.

### V-02 — Atmosphere without an object

Aurora blobs, mesh fields, particles, or large blurred color washes are the hero’s only visual anchor. They pass when light/color generation is the product or a custom field is the signature mechanism.

### V-03 — Generic dark-tech room

Slate-black ground, muted gray body, cyan/violet accents, and translucent panels appear without a supplied dark reference or product reason.

### V-04 — Glass as universal material

Multiple cards, navigation, and text panels use translucent fill, bright borders, and backdrop blur. One functional pane can pass when contrast, fallback, and performance are tested.

### V-05 — Unexplained glow

Several elements emit colored light without a scene light source or data meaning. One product LED, screen, focus state, or deliberate stage light may justify glow.

### V-06 — Generic decorative object

Chrome orb, iridescent blob, glass ribbon, floating cube, stock 3D sculpture, sparkle field, or generic isometric illustration substitutes for a real product, brand form, or narrative object.

### V-07 — Mockup as costume

A phone, laptop, or dashboard frame signals “software” but does not show a real task. Real UI at readable scale, composed around one true workflow, can pass.

### V-08 — Material soup

Grain, glass, glow, gradient type, soft shadow cards, floating mockup, and 3D decoration coexist without one surface logic. Choose the smallest material family that expresses the genome.

### V-09 — OS-language imitation

Another platform’s refractive chrome or spatial UI language is copied onto an unrelated marketing site. It can pass for an actual platform/device product or one localized functional control.

## WATCHLIST

- generic cream paper with no stated stock or print logic;
- three or more saturated accents in one viewport;
- global grain over UI and body text;
- decorative grid or perspective floor;
- meaningless SVG line draw or orbit;
- identical radius and shadow on every image;
- accent stripe as the only difference between cards;
- document-wide cursor ring with no local tool function.

## Stack signals

- dark navy + purple gradient + aurora + glass + glow;
- cream + fashionable grotesk + grain + soft cards + chrome orb;
- particles + shader + magnetic cursor + glass + 3D prop;
- grain + glow + gradient type + rounded cards + floating mockup.

The combination matters more than any single material.

## Critique prompts

1. What is the page’s primary surface or material?
2. Where does light come from?
3. Which object could not be swapped for a stock asset?
4. What remains if grain, glow, glass, and mesh are removed?
