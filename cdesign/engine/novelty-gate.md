# Novelty Gate

Run this gate after DESIGN_GENOME and before code.

## Required output

### SIGNATURE_DECISION

One concrete sentence describing what this site visibly does that a standard generated landing page would not do.

The sentence must name:

- an element or spatial system;
- a behavior or transformation;
- its connection to product, content, or concept.

Example:

> Navigation lives inside a permanent vertical transaction rail that becomes the product timeline as the user scrolls through real workflow states.

### Three identity decisions

List three independently visible decisions that create the identity. At least two must affect structure, content presentation, navigation, typography, imagery, or interaction—not surface decoration.

### REJECTED_DEFAULT

Name one obvious category-template approach that was deliberately rejected and state what replaces it.

Example:

> Rejected: a centered fintech hero above three benefit cards. Replaced with a ledger-like split where the live reconciliation sequence is the page's navigation and proof.

## Automatic FAIL

Fail when the signature or identity decisions rely on:

- asymmetric layout
- big or bold typography
- smooth animations
- modern, clean, premium, cinematic, immersive
- bento grid
- glassmorphism
- 3D object
- dark mode

These may describe implementation details but cannot be the signature.

Also fail when:

- the signature could be pasted into an unrelated brief;
- it exists only in the hero and leaves no trace elsewhere;
- it depends on an asset that does not exist;
- it adds spectacle without improving recognition, explanation, or action;
- the three decisions are cosmetic variations of the same effect.

## Regeneration

On FAIL, do not soften the wording. Change the art direction:

1. return to project evidence;
2. replace the weakest structural decision;
3. rewrite affected genome fields;
4. rerun anti-repetition;
5. rerun this gate.

No implementation begins until the gate passes.
